# Project Title: Resume Classification

## 📌 Overview
This project applies Natural Language Processing to classify resumes into predefined categories such as Data Science, Web Development, HR, etc. It is designed to assist HR teams in screening resumes efficiently.

## 🧠 Objective
To automate resume screening by classifying resume text into relevant job domains using NLP and machine learning.

## 🛠️ Technologies Used
- Python
- NLTK, Scikit-learn
- CountVectorizer / Tfidf
- Streamlit
- Jupyter Notebook

## 📊 Dataset
- Resumes collected and labeled by category
- Each resume processed and vectorized for ML input

## 📈 Model Highlights
- Text preprocessing (tokenization, stopword removal, etc.)
- Classification using models like Logistic Regression / Naive Bayes
- Real-time prediction via Streamlit app

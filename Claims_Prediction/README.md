# Project Title: Claims Prediction

## 📌 Overview
This project focuses on building a predictive model to estimate insurance claim amounts using customer and claim-related data. It applies data preprocessing, exploratory analysis, and regression techniques to develop an accurate and interpretable model.

## 🧠 Objective
To predict the value of insurance claims based on available features and enhance decision-making for underwriting and risk assessment.

## 🛠️ Technologies Used

- Pandas, NumPy
- Scikit-learn
- XGBoost / Ridge / Linear Regression
- Jupyter Notebook
